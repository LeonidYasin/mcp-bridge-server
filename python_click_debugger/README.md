# Набор Python-скриптов для отладки клика и ввода в DeepSeek

В этот набор входят скрипты для автоматического поиска элементов, вставки текста и аппаратного клика с наглядной анимацией курсора.

---

## 🚀 Вариант 1 (НОВЫЙ): `debug_click_ocr.py` — Полный автопилот через OCR
**Самый умный скрипт.** Сам находит на экране поле ввода и кнопку отправки с помощью оптического распознавания текста (OCR):
- Сканирует экран и распознает ключевые маркеры («Глубокое мышление», «Умный поиск», плейсхолдер «Спросите» / текст сообщений).
- Точно вычисляет координаты поля ввода (textarea) и синей кнопки отправки.
- Сохраняет размеченный отладочный скриншот `deepseek_ocr_debug.png` (зеленые рамки текста, желтая точка поля ввода, красный прицел кнопки).
- Плавно ведет курсор в поле ввода, кликает, вставляет текст через Ctrl+V.
- Плавно ведет курсор к кнопке, кружит вокруг нее (прицеливание), щелкает звуком и жмет мышь.

### Установка и запуск:
```bash
pip install easyocr pyautogui pyperclip pillow
python debug_click_ocr.py
```

---

## 🎯 Вариант 2: `debug_click_pyautogui.py` — Быстрая калибровка и клик
Не требует тяжелых библиотек распознавания.
- Режим калибровки: наведите мышь на синюю стрелку на 5 секунд.
- Кликает в поле ввода (на 70px выше кнопки) и вставляет текст через Ctrl+V.
- Плавно ведет курсор к кнопке с круговой анимацией и кликает.

### Запуск:
```bash
pip install pyautogui pyperclip pillow
python debug_click_pyautogui.py
```

---

## 🌐 Вариант 3: `debug_click_cdp.py` — Через Chrome DevTools Protocol
Внедряет лазерный неоновый прицел прямо в веб-страницу и передает аппаратные события клика через порт 9222.
